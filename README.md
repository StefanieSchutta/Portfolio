## Tipps

- **Format:** JPG oder WebP, max. ~300 KB pro Bild (für schnelle Ladezeiten)
- **Komprimieren:** [Squoosh](https://squoosh.app) oder [TinyJPG](https://tinyjpg.com)
- **Dateinamen:** exakt wie oben — klein geschrieben, kein Leerzeichen
- Fotos ohne passende Datei zeigen den Platzhalter-Hintergrund — kein Fehler, kein Absturz

---

## Deployment (GitHub Pages)

1. Repo erstellen (z. B. `echoes-portfolio`)
2. Alle Dateien pushen (`index.html`, `css/`, `js/`, `images/`)
3. Settings → Pages → Branch: `main`, Ordner: `/ (root)`
4. Nach ~1 Minute erreichbar unter `https://USERNAME.github.io/echoes-portfolio`
